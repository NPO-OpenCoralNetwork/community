# 写真の決まり(D3「夕方の写真」)

D3 は MIDORI.so のように、実在の場所と人の写真を主役にするページです。かっこよく見える理由は、写真そのものよりも「撮り方がそろっていること」と「写真の上に置くものが少ないこと」です。

## 枠ごとに要る写真

| 枠 | 向き | 写っているもの |
| --- | --- | --- |
| 最初の画面(パソコン) | 横長。3:2 か 16:9、幅 2200px 以上 | 夕方に灯りを点けた会場。中景で2〜4人が実際に作業か会話をしている。左下が暗く静かで、見出しとボタンを置ける |
| 最初の画面(スマホ) | 縦長。9:16 前後、幅 828px 以上 | 同じ時間、同じ人を縦に組み直したもの。上に照明、真ん中に人、下3分の1は床か机 |
| 次の集まり、活動 | 横長 3:2、幅 1600px 以上 | 窓の自然光か暖かい室内灯。作業や会話の途中。カメラ目線やポーズはなし。手元、少人数の会話、画面を見せて話す人、まちの通りなど |

スマホでは、横長の写真は 4:3 に、活動の最後の写真はパソコンで 21:9 に切り抜いて表示します。主役が中央付近にある写真を選び、ずれるときは `content.yaml` の `focal`(CSS の `object-position`。例:`"42% 62%"`)で残す位置を指定します。

## 撮り方(本番の撮影)

- **夕方の室内(最初の画面):** 日の入りの30〜60分前に会場に着いて準備し、日の入りのあと、室内の灯りと空の明るさが釣り合う10分ほどの間に撮る。三脚で水平、目の高さ、24〜35mm 相当。青白い蛍光灯は消し、暖色の灯りを点ける。
- **横と縦は別々に撮る。** スマホの縦長の画面を写真で埋めると、横 16:9 の写真は幅の中央26%、縦 4:5 は58%、縦 9:16 は82%しか見えない。
- **同じ三脚位置で昼の版も撮る**と、時間帯で写真とキャプションを差し替えられる。
- **ページに載せるのは、最初の画面の縦横に加えて4〜6枚まで。**
- 最初の1回はプロに頼み、以後は撮影係のメンバーが同じ決まりで足していくのが現実的。

## 色調をそろえる

全部の写真に同じ処理を1つだけかけます。写真ごとに白の基準を合わせ直しません。

```sh
python3 skills/lp-build/scripts/images.py grade 元の写真.jpg brand/<団体>/photos/<名前>.jpg
```

処理の中身は、彩度を下げる(黄〜橙と緑はさらに下げる)、明るいところを少し暖かく・暗いところを少し冷たくする、黒を少し持ち上げる、の3つです。それでも1枚だけ冷たい・明るすぎるときは、その写真だけ赤を少し上げて青を少し下げます(例:ImageMagick の `-channel R -evaluate multiply 1.08 -channel B -evaluate multiply 0.84`)。

## 仮置きの写真

本番の写真がそろうまで、デザインを確かめるために公開写真を仮に置くことがあります。

- 使ってよいのは、商用利用できるライセンス(CC0、CC BY、CC BY-SA、パブリックドメイン、ぱくたその規約など)の写真だけ。出典ページ、作者、ライセンスを `content.yaml` の `credits` に書く。CC BY-SA の写真を加工したものは、同じ CC BY-SA で提供する。
- 素材写真の決まり文句(カメラ目線の笑顔、親指を立てる、握手、スーツ、白い背景)、透かし入り、AI で生成した人物は使わない。
- 写っている人は、その団体と関係のない人です。**仮置きの写真のまま広告を出さない。** 広告を出す前に本番の写真に差し替える。
- 運営者の肖像の代わりに、他人の写真を使わない(誤解を招く)。肖像がなければ、その枠を使わない。

## ほかの団体の仮置き写真を流用するとき

- 色調はそろえ済みなので、`images.py grade` はかけ直さない。
- 使う写真だけを `brand/<団体>/photos/` にコピーし、`content.yaml` の `photos` から使わない枠を消す。
- キャプションは写真に写っているものどおりに書く。その団体の会場ではない写真に「会場」と書かない(例:「本棚のある店、夕方。」)。
- 看板や地名から、実在の場所がはっきり分かる写真(商店街の看板など)は、その団体がそこで活動しているように見えるので避ける。
- `credits` は、使う写真の分だけ元の団体からコピーし、`use` をその団体のページでの使い道に合わせる。`photos/CREDITS.md` も同じように作る。

## 写真がそろう前に公開するとき

- 会場の夕方の写真1組(縦と横)だけでも、最初の画面は成り立つ。会場がまだなければ、運営者の縦の肖像1枚に本人の言葉を添える。
- 空の写真欄、灰色の箱、「写真準備中」は置かない。

## 同意

- 「撮ってよいか」と「公開してよいか」は別。参加登録のフォームで撮影の同意を任意で聞き、サイトや広告で顔が大きく出る人とは、別に書面で公開の同意を取る。
- 当日は、ストラップの色などで、撮ってよい人とそうでない人を分ける。
- プロに撮影を頼むときは、著作権の譲渡か利用許諾か、使う媒体(サイト、広告、SNS)と期間を契約に書く。

## キャプションと代替テキスト

- キャプション:「場所の種類、時間帯。」(例:「勉強会の長机、午後。」)。実際の写真と合わせる。何時何分は書かない。
- 代替テキスト(`alt`):写っている内容を1文で。写真を差し替えたら必ず書き直す。
