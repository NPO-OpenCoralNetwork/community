# 最初の集まりの進め方(案)

東京で開く、最初の2回の集まりの案です。まだ案なので、団体で確かめてから使います。

| 回 | 来る人 | 目的 |
| --- | --- | --- |
| 0回目 | 知り合いや団体の人(4〜8人) | 本番の写真を撮る。進め方を試す |
| 1回目 | ページや広告を見て登録した人 | 最初の集まり。2回目にも来てもらう |

進め方は、ページ(`content.yaml`)で約束していることに合わせました。

- まちや暮らしで気になっていることを持ち寄り、AIで整理しながら話す会です。
- 持ち物は、気になっていることを1つ。スマホかパソコンがあれば、AIをその場で一緒に試せます。
- 専門知識や経歴は問いません。
- 登録した人には、集まりの案内と、参加者のチャットへの招待をメールで送ります。
- 顔がはっきり写る写真をサイトや広告に使うときは、あらためて書面で同意をもらいます。

## 決めること

| 項目 | 案 |
| --- | --- |
| 日時 | 土日の夕方か、平日の夜。2時間 |
| 会場 | 窓があり、暖かい色の灯りがある部屋。Wi-Fi と電源があり、10人ほど座れる。貸し会議室、レンタルスペース、区の施設など |
| 参加費 | 決まっていない(ページの `[参加費]`) |
| 使うAI | 入力した内容を学習に使わない設定にできるもの |
| チャット | Discord か Slack(決まっていない) |
| オンライン | 1回目は会場だけにするか、配信もするか |

- 0回目の会場の写真が、ページの最初の画面の写真になります。写真の決まり(lp-build の `references/photo-rules.md`)に合う部屋を選びます。青白い蛍光灯しかない会議室は避けます。
- ページの運営の約束に、「相談の内容や参加者のデータを、AIの学習には使いません」と書いています。
  - 集まりで使う AI は、入力した内容を学習に使わない設定にします。
  - 参加者にも、名前や住所など、個人が分かることを入れないように伝えます。

## 0回目(撮影を兼ねる)

- **時間:** 日の入りをまたぐ時間にします。冬の東京の日の入りは16時半ごろです。日の入りの30〜60分前に会場に入って準備します。
- **人:** 写ってもよい人だけを呼びます。写る人全員から、当日、書面で同意をもらいます(下の同意書の案)。
- **撮る人:** 最初の1回は、プロに頼むのがおすすめです。契約には、次のことを書きます。
  - 著作権を譲ってもらうか、使ってよい範囲を決めるか
  - 使う媒体(サイト、広告、SNS)と期間
- **撮るもの:** `photo-rules.md` の「枠ごとに要る写真」です。最初の画面の写真は、横長と縦長を別々に撮ります。
  - 最初の画面:夕方に灯りを点けた会場で、2〜4人が実際に作業か会話をしているところ
  - 次の集まり、活動:作業や会話の途中。カメラ目線やポーズはなし
- **進め方:** 1回目と同じ進め方で、本当に集まりをします。撮るために演じてもらうより、自然な写真になります。進め方の練習にもなります。

撮ったあとは、次の順で進めます。

1. 写真を選び、`brand/opencoral/photos/` の仮置きの写真と差し替える。
2. `photos/CREDITS.md` と、`content.yaml` の `credits` を直す。
3. ページを組み立て直し、design-review で点検する。

## 1回目の進め方(2時間)

| 時間 | すること |
| --- | --- |
| 0:00〜0:10 | 受付。名札を書き、ストラップを選んでもらう(写ってよい人と、よくない人で色を分ける) |
| 0:10〜0:20 | あいさつ。団体と、この集まりのこと。写真を撮るときの決まり |
| 0:20〜0:40 | 自己紹介。呼んでほしい名前と、気になっていることを1つ |
| 0:40〜1:10 | 3〜4人の組に分かれ、気になっていることをAIで整理してみる。スマホやパソコンがない人は、同じ組の人の画面を一緒に見る |
| 1:10〜1:40 | 組ごとに話し合い、次に小さく試すことを1つ決める。決めるのは人です |
| 1:40〜1:55 | 組ごとに発表。次回の日程と、参加者のチャットの案内 |
| 1:55〜2:00 | 片付け |

## 準備とそのあと

| いつ | すること |
| --- | --- |
| 3週間前まで | 会場を予約する。ページの「次の集まり」に日時と会場を書き、組み立て直す |
| 1週間前 | 登録した人に、案内のメールを送る(日時、会場、持ち物) |
| 前日 | 確認のメールを送る |
| 当日 | 受付の名簿、名札、ストラップ2色、延長コード、モニターとつなぐケーブル。撮影する日は同意書も |
| 2日以内 | お礼のメールを送る。参加者のチャットへの招待と、次回の日程を入れる |
| 2日以内 | 来た人の数、初めて来た人の数、2回目以降の人の数を記録する |

- 名簿には、呼んでほしい名前と、来たかどうかだけを書きます。集めるのは必要な項目だけです。
- 記録は、広告の効果を見ることと、続けるかを決めることに使います(`ads.md` の「毎月すること」)。
