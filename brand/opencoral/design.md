# Open Coral Network のデザインの決まり

2026年10月のデザインリサーチで、方向 D3「夕方の写真」に決めました。経緯は [docs/reports/design-research.md](../../docs/reports/design-research.md) の「新しいデザインの方向性」にあります。

## 方向

- MIDORI.so のように、実在の場所と人の写真を主役にする。
- 最初の画面は夕方の会場の写真1枚を全面に敷き、左下に日本語の見出しと白いボタン、右下に「場所の種類、時間帯。」の小さなキャプションだけを置く。
- 2画面目からは明るい無地の地に、同じ色調の写真4〜6枚と短い文を並べる。
- スマホで7〜9画面に収める。

## 色

差し色は足さず、色は写真に任せます。

| 役割 | 色 | 使う場所 |
| --- | --- | --- |
| 地 | `#ecebe8` | ページの地(明るいグレー) |
| 紙 | `#f7f6f3` | 参加登録の欄 |
| 文字 | `#161615` | 本文、黒いボタン |
| 補助の文字 | `#4b4a46` | 補足、キャプション(地の上で 7.5:1) |
| 罫線 | `#c9c6bf` | 区切りの線 |
| 入力欄の枠 | `#77746d` | フォームの枠(白の上で 4.6:1) |
| エラー | `#a1261b` | 入力の誤り |

写真の上の文字は白。ボタンは、写真の上では白地に黒文字、地の上では黒地に白文字。

## 書体

- 和文は Murecho、欧文と数字は Geist。太さは本文 400、見出し 600。
- 丸ゴシック、明朝の太字、等幅書体は使わない(却下した3案の失敗)。
- 細かい決まりは [lp-build の jp-typography.md](../../plugins/lp-designer/skills/lp-build/references/jp-typography.md)。

## 写真

- いまの写真は仮置き(CC ライセンスの公開写真に色調をそろえたもの)。クレジットは [photos/CREDITS.md](photos/CREDITS.md)。
- 広告を出す前に、初回の撮影で次をそろえる。最初の画面の横と縦(夕方の会場、2〜4人が作業か会話)、勉強会の手元、少人数の会話、画面を見せて話す人、まちの通り。
- 運営者の肖像は、本人の写真を撮るまで使わない。
- 撮り方と同意の決まりは [lp-build の photo-rules.md](../../plugins/lp-designer/skills/lp-build/references/photo-rules.md)。

## やらないこと

- 差し色、グラデーションの背景、札やピル、絵文字、汎用アイコン、角丸カードの入れ子
- 英字のラベル、飾りの番号
- 空の写真欄、「写真準備中」
- 黒と金、丸ゴシックと黄色のような、別の業種に見える組み合わせ
