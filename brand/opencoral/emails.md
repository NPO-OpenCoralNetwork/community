# 参加者に送るメールの文面(案)

参加登録した人に送るメールの文面です。まだ案なので、団体で確かめてから使います。送る時期は、`meetup.md` の「準備とそのあと」に合わせています。

| メール | 送るとき | 送る相手 |
| --- | --- | --- |
| 1. 参加登録のお礼 | 登録があるたび(なるべくその日のうちに) | 登録した人 |
| 2. 次の集まりのお知らせ | 次の集まりの日時と会場が決まったとき | 登録した人全員(案内を止めた人を除く) |
| 3. 席を用意したお知らせ | 参加の返事が来るたび(定員まで) | 返事の早い順に、定員までの人 |
| 4. 定員に達したお知らせ | 定員を超えて返事が来たとき | 定員を超えて返事をした人 |
| 5. 集まりのご案内 | 集まりの1週間前 | 席を用意した人 |
| 6. 前日のご案内 | 集まりの前日 | 席を用意した人 |
| 7. ご参加のお礼 | 集まりから2日以内 | 来た人 |

## 書き方と送り方

- 文章は、lp-build の `references/content-guide.md` の「日本語の書き方」に合わせました。集まりは「集まり」、登録は「参加登録」と呼び、ほかの言葉と混ぜません。
- 事実は、`facts.md` とページの文面にあるものだけを使いました。メールで約束すること(席の決め方、写真、案内の止め方)も、`facts.md` の「集まり」に書いてあります。
- 宛名は「さん」にしました。「様」にするときは、すべてのメールでそろえます。
- 送るアドレスは、返信を受け取れるものにします。参加の返事や、案内を止めたいという連絡を、返信で受け取るためです。問い合わせ先と同じアドレスにすると、窓口が1つで済みます。
- 返信で預かった情報(参加するかどうかなど)は、プライバシーポリシーの「預かる情報」に書いてあります。
- 何人かにまとめて送るときは、ほかの人のアドレスが見えないようにします。メールのサービスで1人ずつ送るか、BCC に入れます。
- 案内を止めたいと連絡があった人には、それ以降どのメールも送りません。

## 仮の値

角括弧の値は、送る前にすべて埋めます。

| 仮の値 | 入れるもの |
| --- | --- |
| `[お名前]` | 参加登録のときに書いてもらった、呼んでほしい名前 |
| `[日時]` | 集まりの日時。`content.yaml` の値から HTML(`<span>` や `<wbr>`)を除いて書く。例:11月14日（土）18:30〜21:00 |
| `[会場]` | 会場の正式な名前 |
| `[行き方]` | 会場までの行き方。載せないと決めたら、その行を消す |
| `[参加費]` | 参加費 |
| `[定員]` | 定員 |
| `[オンライン]` | オンラインで参加できるか。ページで「日程と一緒にお知らせします」と約束している |
| `[チャットの招待リンク]` | 参加者のチャットに入るためのリンク |
| `[公開するURL]` | ページの URL(`https://` で始め、`/` で終わる) |
| `[問い合わせ先のメールアドレス]` | 問い合わせ先 |

## 1. 参加登録のお礼

件名:参加登録を受け付けました（Open Coral Network）

```text
[お名前]さん

コミュニティに参加登録していただき、ありがとうございます。
特定非営利活動法人 Open Coral Network の運営チームです。

参加者のチャット
次のリンクから、参加者のチャットに入れます。
入ったら、興味のあることや得意なこと、参加のきっかけを書いてください。
[チャットの招待リンク]

次の集まり
まちや暮らしで気になっていることを持ち寄り、AIで整理しながら話す会です。
日時：[日時]
会場：[会場]
参加費：[参加費]
定員：[定員]
オンラインでの参加：[オンライン]
持ち物：気になっていることを1つ。スマホかパソコンがあれば、AIをその場で一緒に試せます。

参加するかどうかを、このメールへの返信でお知らせください。
定員を超えたときは、返信の早い順にご案内し、次の回をお知らせします。

専門知識や経歴は問いません。参加はいつでもやめられます。

案内が要らなくなったときや、登録した情報を直したり消したりしたいときは、このメールに返信してください。
預かった情報は、プライバシーポリシーにしたがって扱います。
[公開するURL]privacy.html

特定非営利活動法人 Open Coral Network 運営チーム
お問い合わせ：[問い合わせ先のメールアドレス]
```

次の集まりがまだ決まっていないときは、「次の集まり」から「次の回をお知らせします。」までを、次の1文に差し替えて送ります。

```text
次の集まりの日程は、決まりしだいメールでお知らせします。
```
