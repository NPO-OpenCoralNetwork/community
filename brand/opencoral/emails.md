# 参加者に送るメールの文面(案)

参加登録した人に送る、4通のメールの文面です。まだ案なので、団体で確かめてから使います。送る時期は、`meetup.md` の「準備とそのあと」に合わせています。

| メール | 送るとき | 送る相手 |
| --- | --- | --- |
| 1. 参加登録のお礼 | 登録があるたび(なるべくその日のうちに) | 登録した人 |
| 2. 集まりのご案内 | 集まりの1週間前 | 参加すると返事をした人 |
| 3. 前日のご案内 | 集まりの前日 | 参加すると返事をした人 |
| 4. ご参加のお礼 | 集まりから2日以内 | 来た人 |

書き方と送り方の決まりは、次のとおりです。

- 文章は、lp-build の `references/content-guide.md` の「日本語の書き方」に合わせました。
- 事実は、`facts.md` とページの文面にあるものだけを使いました。
- 決まっていないことは、`[日時]` のように角括弧で示しています。送る前に、すべて埋めます。`[お名前]` には、登録のときに書いてもらった呼んでほしい名前が入ります。
- 宛名は「さん」にしました。「様」にするときは、4通ともそろえます。
- 送るアドレスは、返信を受け取れるものにします。参加するかどうかや、登録の取り消しを、返信で受け取るためです。問い合わせ先と同じアドレスにすると、窓口が1つで済みます。
- 何人かにまとめて送るときは、ほかの人のアドレスが見えないようにします。メールのサービスで1人ずつ送るか、BCC に入れます。
