# 参加者に送るメールの文面(案)

参加登録した人に送るメールと、0回目の集まりに誘う文面です。まだ案なので、団体で確かめてから使います。送る時期は、`meetup.md` の「準備とそのあと」に合わせています。

| メール | 送るとき | 送る相手 |
| --- | --- | --- |
| 0. 0回目に誘う文面 | 0回目の4週間前ごろ | 知り合いや団体の人(写ってもよい人) |
| 1. 参加登録のお礼 | 登録があるたび(なるべくその日のうちに) | 登録した人 |
| 2. 次の集まりのお知らせ | 次の集まりの日時と会場が決まったとき | 登録した人全員(案内を止めた人を除く) |
| 3. 席を用意したお知らせ | 参加の返事が来るたび(定員まで) | 返事の早い順に、定員までの人 |
| 4. 定員に達したお知らせ | 定員を超えて返事が来たとき | 定員を超えて返事をした人 |
| 5. 集まりのご案内 | 集まりの1週間前 | 席を用意した人 |
| 6. 前日のご案内 | 集まりの前日 | 席を用意した人 |
| 7. ご参加のお礼 | 集まりから2日以内 | 来た人 |

## 書き方と送り方

- 文章は、lp-build の `references/content-guide.md` の「日本語の書き方」に合わせました。集まりは「集まり」、登録は「参加登録」と呼び、ほかの言葉と混ぜません。
- 事実は、`facts.md` とページの文面にあるものだけを使いました。メールで約束すること(席の決め方、写真、案内の止め方)も、`facts.md` の「集まり」に書いてあります。
- 宛名は「さん」にしました。「様」にするときは、すべてのメールでそろえます。
- 送るアドレスは、返信を受け取れるものにします。参加の返事や、案内を止めたいという連絡を、返信で受け取るためです。問い合わせ先と同じアドレスにすると、窓口が1つで済みます。
- 返信で預かった情報(参加するかどうかなど)は、プライバシーポリシーの「預かる情報」に書いてあります。
- 何人かにまとめて送るときは、ほかの人のアドレスが見えないようにします。メールのサービスで1人ずつ送るか、BCC に入れます。
- 案内を止めたいと連絡があった人には、それ以降どのメールも送りません。
- 0は、誘う人が自分の名前で送る個人の誘いです。参加登録をした人に送るものではないので、案内の止め方の結びは付けません。
- 書いたら、言葉の点検をします(`python3 scripts/check_wording.py brand/opencoral`)。

## 仮の値

角括弧の値は、送る前にすべて埋めます。

| 仮の値 | 入れるもの |
| --- | --- |
| `[お名前]` | 参加登録のときに書いてもらった、呼んでほしい名前 |
| `[日時]` | 集まりの日時。`content.yaml` の値から HTML(`<span>` や `<wbr>`)を除いて書く。例:11月14日（土）18:30〜21:00 |
| `[会場]` | 会場の正式な名前 |
| `[行き方]` | 会場までの行き方。載せないと決めたら、その行を消す |
| `[参加費]` | 参加費 |
| `[定員]` | 定員 |
| `[オンライン]` | オンラインで参加できるか。ページで「日程と一緒にお知らせします」と約束している |
| `[チャットの招待リンク]` | 参加者のチャットに入るためのリンク |
| `[公開するURL]` | ページの URL(`https://` で始め、`/` で終わる) |
| `[問い合わせ先のメールアドレス]` | 問い合わせ先 |
| `[相手のお名前]` | 0で誘う相手の名前 |
| `[送る人の名前]` | 0を送る人の名前 |
| `[返事の期限]` | 0の返事の期限。日付と曜日で書く。例:11月7日（土）。会場を予約する前(0回目の3週間前まで)にする |

## 0. 0回目に誘う文面

撮影を兼ねた0回目の集まりに、知り合いや団体の人を誘う文面です。メールでもチャットでも送れます。

- 送る前に、`meetup.md` の写真の同意書の案にある `[期間]`、`[日数]`、`[問い合わせ先のメールアドレス]` を決めておきます。この文面で「同意書に書いてある」と約束しているからです。
- 18歳未満の人には、同意書を前もって送ります。
- 返事は、呼んでほしい名前と、来るかどうかだけを管理ツールにまとめます。0回目の受付で使います。
- 来る人が8人を超えたら、返事の早い順に8人までとします。9人目からは、下の「人数がそろったとき」を返します。

件名:集まりの写真の撮影に、参加してもらえませんか

```text
[相手のお名前]さん

特定非営利活動法人 Open Coral Network の[送る人の名前]です。

コミュニティの集まりを始めます。
まちや暮らしで気になっていることを持ち寄り、AIで整理しながら話す会です。

ページや広告で参加者を募る前に、小さな集まりを1回開きます。
この回では、ページと広告に使う写真を撮ります。集まりの進め方も試します。
そこで、写ってもよい方に参加をお願いしています。

日時：[日時]
会場：[会場]
人数：4〜8人ほど
参加費：[参加費]
持ち物：気になっていることを1つ。スマホかパソコンがあれば、AIをその場で一緒に試せます。

写真について
撮った写真は、団体のウェブサイト、広告、SNSで使います。
当日、写真の利用についての同意書に署名をお願いします。使う期間や、同意をやめるときの連絡先も書いてあります。
18歳未満の方は、保護者の方の署名も要ります。同意書を前もってお送りするので、保護者の方に署名してもらい、当日お持ちください。
この回は、写真を撮るための集まりです。写りたくない場合は、この回への参加を遠慮なく断ってください。
1回目からの集まりには、写らずに参加できます。

AIを使ったことがなくても大丈夫です。専門知識や経歴は問いません。
参加できるかどうかを、[返事の期限]までにお知らせください。
8人を超えたときは、返事の早い順に決めます。

[送る人の名前]
特定非営利活動法人 Open Coral Network
```

人数がそろったとき:

```text
[相手のお名前]さん

お返事をありがとうございます。
今回の集まりは、人数がそろいました。お返事をいただいたのに、申し訳ありません。
1回目の集まりの日程が決まったら、お知らせします。

[送る人の名前]
特定非営利活動法人 Open Coral Network
```
