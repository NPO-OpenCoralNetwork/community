# 問い合わせ文の下書き

`outreach-manager` が書く、問い合わせ文の下書きの置き場です。ここにあるものは、まだ送っていない案です。送るのは、人が全文を確かめて承認してからです(`projects/akiya-hub/CLAUDE.md` の運用ルール7)。

## ファイル名

`O-001.md` のように、`data/outreach.csv` の連絡IDにします。同じ相手に2通目を送るときは、新しい連絡IDで新しいファイルにします。

## 書き方

- 団体の名前で外に出す文章なので、`plugins/lp-designer/skills/lp-build/references/content-guide.md` の「日本語の書き方」に合わせる。和文の中のかっことコロンは全角にする。
- 団体の紹介は、`brand/opencoral/facts.md` の「ページでの書き方」だけを使う。拠点はまだ構想の段階なので、「拠点があります」とは書かない。
- 宛名、差出人、連絡先は角括弧のままにする(`[宛名]`、`[差出人の名前]`、`[返信先のメールアドレス]`)。送るときに人が埋める。公開のリポジトリなので、埋めたものをここに保存しない。
- 1通で聞くことは、多くて5つまで。答えやすい順に、番号を付けて並べる。
- 家賃や条件の交渉は、最初の1通ではしない。まず、話を聞いてもらえるかを確かめる。
- 決まっていないこと(予算、入居の時期など)を、決まったように書かない。

## ひな形

````markdown
# O-001 <相手の役割>への問い合わせ(下書き)

- 相手:<役割。例:〇〇市 空き家担当>
- 手段:<メール/問い合わせフォーム/郵送/電話>
- 関連:<P-001 など>
- 目的:<この1通で知りたいこと、頼みたいこと>
- 状態:下書き
- 埋める値:<角括弧の値の一覧>
- 確かめること:<送る前に人が確かめること。例:物件がまだ募集中か>

件名:<件名>

```text
[宛名]

突然のご連絡を失礼いたします。
特定非営利活動法人 Open Coral Network の[差出人の名前]と申します。

<団体の紹介を1〜2文。facts.md の「ページでの書き方」から>

<問い合わせの理由を1〜2文>

<聞きたいことを番号付きで>

<結び>

[差出人の名前]
特定非営利活動法人 Open Coral Network
[返信先のメールアドレス]
```

## 電話のときのメモ

<電話で聞くときは、名乗り方と聞くことの順番を書く。聞いた内容は、outreach.csv の返事の要旨に書く>
````
