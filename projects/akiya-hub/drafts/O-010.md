件名（件名の欄があれば）：空き家利活用補助金交付制度（借りる人のリフォーム）について

```text
[宛名]

突然のご連絡を失礼いたします。
特定非営利活動法人 Open Coral Network の代表理事、[差出人の名前]と申します。
AIを道具にした学びと、居場所づくりに取り組む法人です。

市内で、私の住まいと、地域に開く小さな集まりの場を兼ねて使える戸建ての賃貸を探しています。いまは、不動産会社が掲載している石橋の貸家を見ています。集まりは多いときで20人ほど、音は小さめ（BGMや小さな発表会ほど）です。借りる名義は、私個人か法人かを、補助の条件と所有者の方のお考えを伺ってから決めます。入居は2027年2月ごろを考えています。補助を使う場合は、時期をご相談できればと思います。

空き家利活用補助金交付制度について、次のことを伺えますでしょうか。

1. 私個人が賃貸で借りて住む場合、借りる側としてリフォーム工事の補助を申請できるでしょうか。所有者の方の承諾が要るかも、あわせて伺えますか。
2. NPO法人が借りて私が住む場合は、対象になるでしょうか。案内の所有者の欄の注意書きに「個人事業者及び法人」は補助を受けられないとあり、借りる側にもかかるかを伺いたく思います。
3. 住まいの一部を集まりにも使う家でも、対象になるでしょうか。
4. 空き家バンクに登録されていない、不動産会社が掲載している賃貸でも対象でしょうか。
5. 2026年度の予算の残りを教えてください。2027年度も続ける予定かも、あわせて伺えますか。

お忙しいところ恐れ入りますが、ご教示いただけますと幸いです。

特定非営利活動法人 Open Coral Network
代表理事 [差出人の名前]
[返信先のメールアドレス]
```

- 宛名は課あてにする（例：「住宅建築課 御中」）。担当者の名前がわかっても、このファイルには書かない。
- 5の後半（2027年度）は依頼の4つに足した問い。市のページでは、実績報告は事業の完了から30日以内か2027-03-15の早いほうまで。2027年2月ごろの入居だと、2026年度のうちに工事と報告を終えるのは難しいかもしれないので、2027年度のことも聞いた。要らなければ消す。
- 3では、集まりの人数と音だけを書き、夜の時間は書いていない。補助の対象かどうかに関わらないと考えたため。

## 電話のときのメモ

フォームの返事のあとに電話で聞くか、フォームの代わりに電話にするときに使う。電話番号は市のページ（https://www.city.higashimatsuyama.lg.jp/soshiki/37/4112.html の問い合わせ先。住宅建築課（住宅）の番号）で確かめる。

名乗り方

```text
お忙しいところ失礼いたします。特定非営利活動法人 Open Coral Network の代表理事、[差出人の名前]と申します。空き家利活用補助金交付制度について伺いたく、お電話しました。住宅のご担当の方にお願いできますでしょうか。
```

フォームを送ったあとなら、「[送信日]にフォームでお問い合わせした件です」と足す。

聞く順番（フォームに入らなかったこと）

1. 交付の申請は工事の前か。申請から交付の決定までの日数。補助が払われる時期（実績報告のあとか）
2. 「おおむね1年以上使用されていない」の確かめ方（だれが、何で確かめるか）
3. 「5年以上居住する意思」の確かめ方（誓約書などか）。住む年数は人が決める。その場で約束しない
4. 借りる側が自分でする改修（DIY）の材料費も対象になるか。施工の業者の条件（市内の業者だと加算がある）
5. 空き家バンクの利用の申込み（借りたい側）を、NPO法人の名義でできるか
