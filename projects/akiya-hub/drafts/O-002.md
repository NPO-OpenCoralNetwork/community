件名：空き家バンク賃貸登録物件リフォーム補助と戸建賃貸住宅家賃補助について

```text
[宛名]

突然のご連絡を失礼いたします。
特定非営利活動法人 Open Coral Network の[差出人の役職]、[差出人の名前]と申します。
当法人は、AIを道具にした学びと、居場所づくりに取り組んでいます。

佐倉市で、私の住まいと、地域に開く集まりの場を兼ねて使える戸建ての賃貸を探しています。集まりは多いときで20人ほど、音は小さめ（BGMや小さな発表会ほど）です。空き家バンクの賃貸と、不動産会社が掲載している戸建ての両方を見ています。
借りる名義は、私個人か法人かを、補助の条件と所有者の方のお考えを伺ってから決めます。入居は2027年2月ごろを考えています。補助を使う場合は、時期をご相談できればと思います。

空き家バンク賃貸登録物件リフォーム補助と、戸建賃貸住宅家賃補助について、次のことを伺えますでしょうか。

1. 2026年度の、家賃補助の残りの件数と、リフォーム補助の予算の残りを教えてください。
2. 同じ家で、2つの補助を両方使えるでしょうか。
3. 住まいの一部を集まりにも使う家でも、2つの補助の対象になるでしょうか。リフォーム補助では、集まりに使う部屋の改修も対象になるかを伺えますか。
4. 借りる名義による扱いを教えてください。私個人が借りる場合と、NPO法人が借りて私が住む場合です。案内を拝見し、法人の名義ではどちらも対象外と読みましたが、念のため伺います。
5. 空き家バンクのNo.135（宮前二丁目の賃貸）は、いまも募集中でしょうか。

お忙しいところ恐れ入りますが、ご教示いただけますと幸いです。

[差出人の名前]
特定非営利活動法人 Open Coral Network
[返信先のメールアドレス]
```

- 宛名は部署あてにする（例：「住宅課 住生活推進班 御中」）。担当者の名前がわかっても、このファイルには書かない。
- 4の「法人の名義ではどちらも対象外と読みました」は、こちらの読み方として書いた。根拠は、リフォーム補助の案内の「法人は対象外」と、家賃補助の「世帯主か同居の世帯員が契約したもの」（`data/municipalities.csv` の M-047、M-048）。

## 電話のときのメモ

フォームの返事のあとに電話で聞くか、フォームの代わりに電話にするときに使う。電話番号は市のページ（https://www.city.sakura.lg.jp/soshiki/jutakuka/103/5744.html の問い合わせ先）で確かめる。

```text
お忙しいところ失礼いたします。特定非営利活動法人 Open Coral Network の[差出人の役職]、[差出人の名前]と申します。空き家バンクの賃貸のリフォーム補助と、戸建て賃貸の家賃補助について伺いたく、お電話しました。住生活推進班の方にお願いできますでしょうか。
```

フォームを送ったあとなら、「[送信日]にフォームでお問い合わせした件です」と足す。

聞く順番（フォームに入らなかったこと）

1. 2つの補助は、2027年度も続く予定か（契約や工事が2027年4月より後になるとき）
2. 空き家バンクに、NPO法人として利用登録できるか（利用申込書と誓約書）
3. リフォーム補助の、施工の業者の条件（市内の業者に限るか）と、着工の前の申請から交付の決定までの日数
4. リフォーム補助で、借りる側が自分でする改修（DIY）の材料費も対象になるか

聞いたあと

- 聞いた内容をメインエージェントに渡す。outreach-manager が `data/outreach.csv` の返事の要旨に書く。
- 世帯のことを聞かれたら、答えるかは人が決める。答えたことはリポジトリに書かない。
