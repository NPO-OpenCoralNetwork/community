# データの決まり

4つの CSV の、列と値の決まりです。どれも UTF-8 で、1行目が列名です。列名は変えません。

## どのファイルにも共通

| 列 | 書くこと |
| --- | --- |
| ID | `P-001`(物件)、`M-001`(自治体の制度)、`F-001`(資金)、`O-001`(連絡)。番号は使い回さない。行を消さない |
| `出典URL` | 確かめたページの URL。いくつかあるときは `;` で区切る。人から聞いたことは、`data/outreach.csv` の連絡ID(`O-003` など)を書く |
| `確認日` | 出典を実際に開いて確かめた日。`YYYY-MM-DD` |
| `確度` | `確認済み`、`未確認`、`推測` のどれか。意味は `projects/akiya-hub/CLAUDE.md` の運用ルール2 |
| `未確認の項目` | 確かめていない列の名前を、`、` で区切って書く。例:`音出し、用途地域` |
| `次の行動` | 次にだれが何をするか。例:`municipality-researcher が用途地域を確かめる` |
| `メモ` | ほかの列に入らないこと。個人に関わることは書かない |

- 金額は、円の整数で書く(`85000`)。カンマや「万」は使わない。わからなければ空にする。
- 選ぶ値が決まっている列は、下の表の値だけを使う。わからなければ `不明`。
- 名前、電話番号、メールアドレス、番地を書かない(`projects/akiya-hub/CLAUDE.md` の「個人情報と公開」)。

## properties.csv(物件候補)

| 列 | 書くこと |
| --- | --- |
| `物件ID` | `P-001` から |
| `検討段階` | `候補`、`問い合わせ中`、`内見予定`、`内見済み`、`交渉中`、`契約`、`見送り`、`参考` |
| `募集状況` | `募集中`、`募集終了`、`不明`、`非公開`(掲載はないが、所有者や自治体から紹介された) |
| `取引` | `賃貸`、`売買`、`賃貸・売買`、`不明` |
| `入手経路` | `空き家バンク`、`所有者と直接`、`不動産会社`、`不動産サイト`、`自治体の紹介`、`人の紹介`、`その他` |
| `物件名` | 掲載の題名か、短い説明(例:`平屋 5DK 庭付き`) |
| `都道府県`、`市区町村`、`町名` | 町名まで。番地は書かない |
| `最寄り駅` | `〇〇線 〇〇駅`。いくつかあるときは `;` で区切る |
| `駅から` | `徒歩12分`、`バス15分+徒歩3分` など |
| `都心まで` | 基準の駅までの所要時間と乗り換え。例:`新宿 55分(乗換1回)`。基準の駅は企画書の「決めること」 |
| `交通の出典URL`、`交通の確認日` | 交通の列の出典と確認日。物件の `出典URL`、`確認日` とは別に書く |
| `家賃_月額_円`、`価格_円`、`初期費用_円` | 円の整数。初期費用は、敷金・礼金・仲介手数料などのわかる分の合計 |
| `間取り`、`建物面積_㎡`、`土地面積_㎡`、`築年` | 築年は西暦の4桁 |
| `建物の状態` | `すぐ住める`、`小さな修繕`、`大きな改修`、`不明` |
| `用途地域` | 都市計画の用途地域の名前 |
| `事業利用`、`音出し`、`改修` | `可`、`相談可`、`不可`、`不明`。事業利用は、集まりやNPOの活動に使えるか。改修は DIY を含む |
| `契約の形` | 普通借家、定期借家、DIY可、使用貸借、相談可 など。わかることを書く |
| `所有者と直接` | `はい`、`仲介あり`、`不明` |
| `両立の見込み` | 居住とNPO活動の両立の見込み。`高い`、`ある`、`低い`、`不明`。理由を `メモ` に書く。判断に推測を含むときは `確度` を `推測` にするか、`未確認の項目` に書く |
| `掲載URL` | 物件の掲載ページ |

- **現行候補**は、`募集状況` が `募集中` か `非公開` で、`検討段階` が `見送り`・`参考` 以外のものです。
- `募集終了` の行は、`検討段階` を `参考` か `見送り` にします。
- `募集中` の確認日が14日より古いときは、点検で注意が出ます。確かめ直します。

## municipalities.csv(自治体・制度一覧)

申し込む先や窓口が自治体(都道府県、市区町村)の制度を書きます。国の制度でも、申し込む先が市区町村ならここに書きます。

| 列 | 書くこと |
| --- | --- |
| `制度ID` | `M-001` から |
| `都道府県`、`市区町村` | 都道府県の制度なら `市区町村` は空 |
| `種類` | `空き家バンク`、`所有者マッチング`、`改修の補助`、`取得の補助`、`家賃の補助`、`移住の支援`、`お試し居住`、`地域活動の支援`、`相談窓口`、`規制・手続き`、`その他` |
| `制度名`、`内容`、`対象・条件`、`金額・上限` | 公式の名前と、要点 |
| `法人の利用` | NPO法人が使えるか。`可`、`個人のみ`、`不明` |
| `両立への影響` | 居住とNPO活動の両立に関わること。例:`住宅の部分だけが対象`、`地域に開く活動なら加点` |
| `受付状況` | `受付中`、`受付前`、`受付終了`、`通年`、`不明` |
| `受付期間` | 公式の書き方で。年度を付ける。例:`2026年度 5月〜予算に達するまで` |
| `締切` | 締切の日がわかれば `YYYY-MM-DD` |
| `窓口` | 課や係の名前まで。担当者の名前は書かない |
| `関連物件ID` | 関係する物件の ID。`;` で区切る |

## funding.csv(自治体以外の資金)

国の機関、財団、企業、金融機関、寄付やクラウドファンディングなど、申し込む先が自治体でない資金を書きます。

| 列 | 書くこと |
| --- | --- |
| `資金ID` | `F-001` から |
| `種類` | `助成金`、`補助金`、`融資`、`寄付`、`クラウドファンディング`、`協賛`、`その他` |
| `名称`、`実施主体` | 公式の名前 |
| `対象` | 応募できる人や団体 |
| `使い道` | 対象になる費用(改修、家賃、活動費、設備など) |
| `金額・上限`、`補助率・自己負担` | 公式の書き方で |
| `法人の応募` | NPO法人が応募できるか。`可`、`不可`、`不明` |
| `居住部分` | 住居の部分の費用に使えるか。`対象`、`対象外`、`不明` |
| `受付状況` | `受付中`、`受付前`、`受付終了`、`通年`、`不明` |
| `締切` | `YYYY-MM-DD` |
| `応募の状態` | `調査中`、`候補`、`準備中`、`応募済み`、`採択`、`不採択`、`見送り` |
| `関連ID` | 関係する物件や制度の ID |

## outreach.csv(問い合わせ履歴)

| 列 | 書くこと |
| --- | --- |
| `連絡ID` | `O-001` から |
| `作成日` | 行を作った日 |
| `相手の種類` | `所有者`、`不動産会社`、`自治体`、`空き家バンク`、`支援団体`、`助成団体`、`専門家`、`その他` |
| `相手` | 役割で書く。例:`P-003 の所有者`、`〇〇市 空き家担当` |
| `関連ID` | 関係する物件、制度、資金の ID |
| `手段` | `メール`、`問い合わせフォーム`、`電話`、`訪問`、`郵送`、`その他` |
| `要旨` | 何を聞くか、何を頼むか |
| `下書き` | 下書きのファイル。例:`drafts/O-001.md` |
| `状態` | `下書き`、`承認待ち`、`承認済み`、`送信済み`、`返事あり`、`やりとり中`、`終了`、`見送り` |
| `承認日`、`承認した人` | 送る前に人が承認した日と、その人の役割(例:`代表`)。名前は書かない |
| `送信日` | 送った日 |
| `返事の要旨` | 返事の要点。個人に関わることは書かない |
| `次の行動`、`期日` | 次にすることと、その期日(`YYYY-MM-DD`)。返事を待つときは、確かめ直す日 |

- メール、問い合わせフォーム、郵送、その他の手段で送るものは、`承認済み` より先の `状態` に `承認日` と `承認した人` が要ります。電話と訪問は、人が自分でするので要りません。
- `送信済み` より先の `状態` には、`送信日` が要ります。
- `期日` を過ぎた行は、点検で注意が出ます。

## Excel で開くとき

ダブルクリックで開くと、文字化けすることがあります。Excel の「データ」→「テキストまたは CSV から」で、文字コードを UTF-8 にして読み込みます。Google スプレッドシートなら、そのまま読み込めます。
