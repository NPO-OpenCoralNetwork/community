### 条件から考えたこと

- 推測:家賃10万円の物件で、敷金・礼金・仲介手数料が1か月分ずつだと、それだけで30万円になる。初期費用と改修を30万円に収めるには、敷金や礼金の少ない物件、改修を所有者が受け持つ物件を探す必要がある。根拠:4. の家賃と初期費用の上限。
- 推測:入居まで3か月なので、大きな改修が要る物件は間に合いにくい。「すぐ住める」「小さな修繕」の物件を先に見る。根拠:4. の入居の時期と、改修の予算。
- 推測:集まりは20人までで、音は小さめなので、住宅地の戸建てでも両立できる余地がある。ただし、人の出入り、駐車、消防の決まりは、物件ごとに確かめる。根拠:3. と 4.。

## 5. 探し方

- **範囲**:東京都の多摩地域、神奈川県、埼玉県、千葉県。物件から(駅までの徒歩や路線バスを含めて)、普通列車と路線バスで、新宿駅か東京駅の近いほうまで120分以内。特急、新幹線、高速バスでしか入らないものは外す。夜21時ごろに終わる集まりから、その日のうちに帰れること。出典:回答(2026-11-05)
- **探す先**:自治体の空き家バンク、所有者と直接やりとりできるサイト、自治体の相談窓口、地元の不動産会社、不動産サイトの賃貸。
- **取引**:賃貸だけ。定期借家、使用貸借、DIY を認める賃貸なども含む。
- **家賃**:月10万円まで。5万円では切らない。比べるときは、初期費用と改修を含めた総額で比べる。
- **契約**:所有者と直接話せる物件と、柔軟な契約を相談できる物件を重く見る。
- **両立**:居住とNPO活動を両立できるかを、契約、法令と手続き、近隣、建物、費用の分け方の5つの面で見る(`CLAUDE.md` の運用ルール6)。

## 6. 評価の軸(案)

重みと順番は人が決めます。決まるまでは、運用ルールに合わせ、両立と契約の柔軟さを先に見ます。初期費用と改修の予算が小さいので、初期費用と建物の状態も先に見ます。自治体の改修の補助を使える物件は、入居が遅れても重く見ます(回答、2026-11-05)。

**外せない条件**(満たさないものは現行候補にしない)

- 募集中である。または、所有者や自治体と直接話せている
- 賃貸で、家賃が月10万円以内
- 範囲の中にあり、物件から普通列車と路線バスで、新宿駅か東京駅の近いほうまで120分以内
- 21時ごろに終わる集まりから、その日のうちに新宿駅か東京駅まで帰れる
- 住める。または、小さな修繕で住める見込みがある
- 契約や法令の面で、NPO活動との両立が否定されていない

**比べる軸**

| 軸 | 見ること |
| --- | --- |
| 両立 | 住む部分と集まる部分、20人が集まれるか、人の出入り、契約での活動利用 |
| 契約の柔軟さ | 所有者と直接話せるか。定期借家、DIY、改修費と家賃の相殺、段階的な家賃を相談できるか |
| 総額 | 家賃、初期費用(敷金・礼金・仲介手数料)、改修、毎月の固定費、交通 |
| 建物 | 状態、広さ、改修の量。3か月で住めるか |
| アクセス | 代表者の移動。集まりに来る人の来やすさ(駅からの距離、バス、夜の帰り道) |
| 自治体の支援 | 補助、マッチング、相談窓口、地域とのつながり |
| 地域 | 地域交流の相手がいるか |
