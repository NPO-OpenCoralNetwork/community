## 5. 探し方

- **範囲**:東京近郊。具体的な範囲は [未定]。
- **探す先**:自治体の空き家バンク、所有者と直接やりとりできるサイト、自治体の相談窓口、地元の不動産会社、不動産サイト(賃貸と売買)。
- **家賃**:検索で上限を切らない。5万円は上限にしない。総額で比べる。
- **契約**:所有者と直接話せる物件と、柔軟な契約を相談できる物件を重く見る。
- **両立**:居住とNPO活動を両立できるかを、契約、法令と手続き、近隣、建物、費用の分け方の5つの面で見る(`CLAUDE.md` の運用ルール6)。

## 6. 評価の軸(案)

重みと順番は人が決めます。決まるまでは、運用ルールに合わせ、両立と契約の柔軟さを先に見ます。

**外せない条件**(満たさないものは現行候補にしない)

- 募集中である。または、所有者や自治体と直接話せている
- 住める。または、改修すれば住める見込みがある
- 契約や法令の面で、NPO活動との両立が否定されていない

**比べる軸**

| 軸 | 見ること |
| --- | --- |
| 両立 | 住む部分と集まる部分、音、人の出入り、契約での活動利用 |
| 契約の柔軟さ | 所有者と直接話せるか。定期借家、DIY、相殺、段階的な家賃、買い取りを相談できるか |
| 総額 | 家賃か価格、初期費用、改修、毎月の固定費、交通 |
| アクセス | 代表者の移動。集まりに来る人の来やすさ(駅からの距離、バス、夜の帰り道) |
| 建物 | 状態、広さ、改修の量 |
| 自治体の支援 | 補助、マッチング、相談窓口、地域とのつながり |
| 地域 | 地域交流の相手がいるか |

## 12. 次にやること

1. 人が「11. 決めること」の1〜5に答える。
2. municipality-researcher:範囲の自治体の空き家バンク、所有者マッチング、改修や移住の支援を一覧にする。
3. property-researcher:範囲の物件を、家賃で上限を切らずに広く集める。
4. funding-researcher:改修と活動の設備に使えそうな、自治体以外の資金を集める。
