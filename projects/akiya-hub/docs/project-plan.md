## 1. 目的

東京近郊の空き家を活用し、次の2つを確保します。

- 代表者の住居
- 音楽・アート・AI・地域交流を行うコミュニティ拠点

### 条件から考えたこと

- 推測:家賃10万円の物件で、敷金・礼金・仲介手数料が1か月分ずつだと、それだけで30万円になる。初期費用と改修を30万円に収めるには、敷金や礼金の少ない物件、改修を所有者が受け持つ物件を探す必要がある。根拠:4. の家賃と初期費用の上限。
- 推測:入居まで3か月なので、大きな改修が要る物件は間に合いにくい。「すぐ住める」「小さな修繕」の物件を先に見る。根拠:4. の入居の時期と、改修の予算。
- 推測:集まりは20人までで、音は小さめなので、住宅地の戸建てでも両立できる余地がある。ただし、人の出入り、駐車、消防の決まりは、物件ごとに確かめる。根拠:3. と 4.。

## 5. 探し方

- **範囲**:東京都の多摩地域、神奈川県、埼玉県、千葉県。新宿駅か東京駅の、近いほうまで120分以内。出典:回答(2026-11-05)
- **探す先**:自治体の空き家バンク、所有者と直接やりとりできるサイト、自治体の相談窓口、地元の不動産会社、不動産サイトの賃貸。
- **取引**:賃貸だけ。定期借家、使用貸借、DIY を認める賃貸なども含む。
- **家賃**:月10万円まで。5万円では切らない。比べるときは、初期費用と改修を含めた総額で比べる。
- **契約**:所有者と直接話せる物件と、柔軟な契約を相談できる物件を重く見る。
- **両立**:居住とNPO活動を両立できるかを、契約、法令と手続き、近隣、建物、費用の分け方の5つの面で見る(`CLAUDE.md` の運用ルール6)。

## 6. 評価の軸(案)

重みと順番は人が決めます。決まるまでは、運用ルールに合わせ、両立と契約の柔軟さを先に見ます。初期費用と改修の予算が小さいので、初期費用と建物の状態も先に見ます。自治体の改修の補助を使える物件は、入居が遅れても重く見ます(回答、2026-11-05)。

**外せない条件**(満たさないものは現行候補にしない)

- 募集中である。または、所有者や自治体と直接話せている
- 賃貸で、家賃が月10万円以内
- 範囲の中にあり、新宿駅か東京駅の近いほうまで120分以内
- 住める。または、小さな修繕で住める見込みがある
- 契約や法令の面で、NPO活動との両立が否定されていない

**比べる軸**

| 軸 | 見ること |
| --- | --- |
| 両立 | 住む部分と集まる部分、20人が集まれるか、人の出入り、契約での活動利用 |
| 契約の柔軟さ | 所有者と直接話せるか。定期借家、DIY、改修費と家賃の相殺、段階的な家賃を相談できるか |
| 総額 | 家賃、初期費用(敷金・礼金・仲介手数料)、改修、毎月の固定費、交通 |
| 建物 | 状態、広さ、改修の量。3か月で住めるか |
| アクセス | 代表者の移動。集まりに来る人の来やすさ(駅からの距離、バス、夜の帰り道) |
| 自治体の支援 | 補助、マッチング、相談窓口、地域とのつながり |
| 地域 | 地域交流の相手がいるか |

## 10. わかったこと

調査の要点です。詳しくは `reports/` と `data/` にあります。

**物件**(`reports/2026-11-05-property-wide-scan.md`、`reports/2026-11-05-property-subsidy-areas.md`)

- 現行候補は22件。見送り3件(P-002〜P-004、初期費用が30万円を超える)、参考3件(P-016、P-022、P-023)。
- 千葉県(佐倉市、大多喜町)と神奈川県秦野市に、広さと家賃の両方で合う物件が多い。東京都の多摩地域は、家賃10万円以内で14畳ほどの部屋がある戸建てが少ない。確度:確認済み(調べた範囲で)。
- 補助のある地域(木更津市、青梅市、八王子市、相模原市緑区)では、条件に合う賃貸がほとんど見つからなかった。木更津市の空家バンクの賃貸(P-024)は60㎡で狭い。
- 不動産サイトの物件は、初期費用が23〜31万円になるものが多い。空き家バンクの物件は低いものが多い(P-026、P-027 は5万円以下、P-028 は17万円台)。
- 掲載に額のない必須の費用(損害保険など)で、30万円を超えるかが変わる物件がある(P-008、P-020)。

**自治体**(`reports/2026-11-05-municipality-wide-scan.md`、`reports/2026-11-05-municipality-candidate-towns.md`)

- 25市町村を調べ、60件の制度を記録した。空き家バンクの賃貸の掲載は、どこも0〜数件。秦野市は多い。
- 借りる人が2026年度に使える100万円規模の補助は、木更津市(M-031、地域拠点の枠は3分の2・上限150万円)と青梅市(M-003、地域交流拠点、3分の2・上限100万円)だけ。物件の候補が多い大多喜町、佐倉市、茂原市、横須賀市にはない。
- **補助の多くは、個人の名義が前提。** 佐倉市の補助はどれも個人だけ。秦野市の賃借者リフォーム補助(M-015)は「会社等」が対象外。大多喜町の補助も個人。NPO法人の名義で借りると、使えない補助が多い。
- 補助は、工事の前に申請し、交付の決定を待つ。推測:支払いは工事のあとが多く、改修費を先に払う資金が要る。根拠:物件の調査と自治体の調査のどちらでも、支払いの時期を確かめられていない。
- 規制の調べる先がわかった。P-014 の浸水は大多喜町 総務課 消防防災係(M-042)。P-013 の2階での集まりは、夷隅郡市広域市町村圏事務組合 消防本部 予防課(M-043)と千葉県 長生土木事務所(M-044)。

**資金**(`reports/2026-11-05-funding-wide-scan.md`)

- 「7. 資金」のとおり。入居までに入る助成金はない。F-001 年賀寄付金は応募の準備中(`docs/f-001-nenga-kifukin.md`、`docs/f-001-nenga-draft.md`)。

**突き合わせてわかったこと**

- **補助の大きい地域と、合う物件のある地域が重ならない。** 補助を重く見るなら、木更津市や青梅市で物件を待つか、所有者を探すことになる。物件を重く見るなら、大多喜町、秦野市、佐倉市の小さい補助を組み合わせる。
