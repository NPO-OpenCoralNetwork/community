# 大多喜町 空き家・空き地バンクの利用登録

- 決めたこと:登録する(回答、2026-11-05)。そのあと、交通の調査を受けて、**いまは止める**(回答、2026-11-05)。普通列車と路線バスでは東京駅まで2時間41分かかり、21時の集まりから帰れないため。大多喜町は予備にし、いすみ鉄道が戻ったら(2027年秋ごろの見込み)見直す
- 目的:P-028(No.98)、P-014(No.135)、P-013(No.141)の見学と問い合わせ
- 出典:[物件情報のページ](https://www.town.otaki.chiba.jp/kanko_iju_bunka/kanko_iju/ijyu/2/1146.html)、[仕組みと利用の流れ](https://www.town.otaki.chiba.jp/kanko_iju_bunka/kanko_iju/ijyu/2/1135.html)、[利用希望者登録申込書と誓約書(PDF)](https://www.town.otaki.chiba.jp/material/files/group/5/akiyaformuse_pdf.pdf)、[制度要綱(PDF)](https://www.town.otaki.chiba.jp/material/files/group/5/akiyaseidoyoukou.pdf)。どれも 2026-11-05 に開いて確かめた

## 流れ

1. 「利用希望者登録申込書」(第4号様式)と「誓約書」(第5号様式)を、町の企画課 地域振興係に出す。様式は PDF と Word がある。
2. 町が、出した内容を、その物件を担当する協力不動産会社と共有する。
3. 不動産会社から連絡があり、見学の日を決める。
4. 見学し、家賃や入居の時期を、不動産会社を通じて所有者と相談する。
5. 不動産会社の仲介で契約する。仲介手数料がかかる。

町は物件を調べていません。物件の状態や契約の中身は、自分で確かめます(町のページの注意)。

## 申込書に書くこと

| 欄 | 書くこと |
| --- | --- |
| 申込者 | 住所、氏名、生年月日、電話、FAX、メール |
| 利用の目的 | 定住、定期的利用、その他から選ぶ |
| 売買か賃貸か、希望の額 | 賃貸と、希望家賃の月額 |
| 家族の状況 | 住むために借りるときだけ。氏名、生年月日、年齢、続柄、勤務先 |
| 希望する所在地や状況 | 見学したい物件の番号など |
| 農業の希望 | 本格的にする、自給的にする、しない |
| その他の希望条件 | 自由に書ける |
| 連絡方法 | 郵送、FAX、メール |
| 同意 | 内容を不動産会社と共有することへの同意 |

個人の情報なので、このリポジトリには書きません。申込書に直接書いてください。

## 誓約書で約束すること

1. 要綱の条件のどれかに当たる。たとえば、定住するか定期的に滞在して地域の活性化に寄与し、よき地域住民として生活しようとする者。
2. 得た情報を、利用の目的のためだけに使う。
3. 物件の瑕疵や、所有者との交渉と契約について、町に責任を求めない。
4. 地域と協調し、地域の取り決めを守る。

## 名義

- 個人も法人も登録できる。
- 町の補助(家財の撤去 M-039 など)を使えるのは、3年以上大多喜町に住む予定の個人だけ。
- 推測:補助を使う余地を残すなら、代表者個人で登録するのがよい。根拠:町の補助は個人だけが対象。名義は物件ごとに決める(企画書の「11.」の20)ので、見学のあとで決め直せる。

## 「その他の希望条件」の文の案

集まりに使うことを、先に正直に伝えます。あとで揉めないためです。

```text
住まいとして定住し、あわせて地域に開く小さな集まりの場（多いときで20人ほど、音は小さめ）としても使いたいと考えています。特定非営利活動法人 Open Coral Network の活動（AIの勉強会や地域の交流）に使う予定です。登録番号 No.98、No.135、No.141 の見学を希望します。
```

- 希望家賃の欄は、人が決めて書きます。企画書の上限は月10万円です。
