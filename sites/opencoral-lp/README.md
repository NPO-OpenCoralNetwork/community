# Open Coral Network 参加登録ページ

Google Ad Grants の検索広告から来た人に、無料の参加登録をしてもらうための1ページのサイトです。デザインは D3「夕方の写真」(写真を主役にしたページ)です。

このフォルダは `brand/opencoral/content.yaml` から組み立てたものです。文面や写真を変えるときは、HTML を直接直さず、`content.yaml` を直して組み立て直します。AI エージェントには「ページを組み立て直して」と頼みます(lp-build スキル)。手で組み立てるときは、リポジトリのルートで次を実行します。

```sh
python3 plugins/lp-designer/skills/lp-build/scripts/build_site.py --brand brand/opencoral --out sites/opencoral-lp
```

## 中身

```
opencoral-lp/
├─ index.html          参加登録ページ(広告のリンク先)
├─ thanks.html         登録のあとに表示するお礼ページ(コンバージョンを数えるページ)
├─ assets/css/style.css
├─ assets/js/main.js   フォームの入力チェックと送信、スマホ下部の登録ボタン
└─ assets/img/         写真(AVIF・WebP・JPEG、幅ごとに複数)
```

`index.html` をブラウザで開けば確認できます。ただし、ロゴと「トップページに戻る」は `./` へのリンクなので、ファイルを直接開いたときはフォルダの一覧が出ます。リンクまで確かめるときは、このフォルダで `python3 -m http.server` を動かし、`http://localhost:8000/` を開きます。書体は Google Fonts から読み込むので、表示にはインターネット接続が必要です。

## 参加登録フォーム

送信先は `content.yaml` の `join.endpoint` と `join.redirect` で決めます。組み立てると、フォームの `data-endpoint`、`action`、`data-redirect` に入ります。

- `endpoint` には、フォームの内容を受け取るサービスの URL を入れます。送信は `FormData` を `POST` で送り、2xx が返れば成功として扱います(例:Formspree)。JavaScript が動かないブラウザでも `action` に送られます。
- `endpoint` が空のあいだは、どこにも送信しません。入力チェックとお礼ページへの移動だけを確かめられます。
- `redirect` は、送信できたあとに移るページです。空にすると、ページ内に「参加登録を受け付けました。」を表示します。ただしお礼ページが表示されないので、下の「計測」の手順ではコンバージョンを数えられません。

送る項目は `nickname`(お名前)、`email`、`interest`(関心のあること、複数可)、`photo_consent`(記録写真への同意、任意)です。ボット対策の見えない欄 `website` は、送信前に取り除きます。

## 計測(Google 広告のコンバージョン)

Ad Grants では、毎月1件以上のコンバージョンを計測する必要があります。

1. Google 広告で「ウェブサイトのコンバージョン」を作り、Google タグの ID(`AW-` で始まる)と、イベント スニペットの `send_to`(`AW-…/…`)を控えます。
2. `content.yaml` の `measure` に書いて、組み立て直します。Google タグは `index.html` と `thanks.html` の両方に、コンバージョンのイベントは `thanks.html` にだけ入ります。お礼ページが表示された回数が、参加登録の数になります。

   ```yaml
   measure:
     google_tag_id: AW-123456789
     conversion_send_to: AW-123456789/AbCdEfGhIj
   ```

組み立てた HTML にタグを手で貼らないでください。次に組み立てると消えます。テストの登録が数えられないよう、`measure` を書くのは `endpoint` を設定したあとにします。

`main.js` は送信に成功したとき(`endpoint` が空の確認用の動きのときも)、`sign_up` のイベントを Google タグと `dataLayer` に送ります。`redirect` を空にしてお礼ページを使わないときは、これをきっかけにコンバージョンを数える設定にします。

## 写真

いまの写真は、デザインを確かめるための仮置きです。公開されている CC ライセンスの写真を、色調をそろえて使っています。クレジットはフッターの「写真について」に載せています。

- 写っている人は、この団体とは関係のない人です。ライセンスがあっても、広告に顔を使う同意まではありません。**広告を出す前に、実際に撮った写真に差し替えてください。**
- 差し替えたら(`og.jpg` も含めて)、`content.yaml` の `credits` を空にしてください。`og.jpg` は最初の画面と同じ写真から切り出しています。

写真の元のファイルは `brand/opencoral/photos/` にあります。差し替えるときは元のファイルを置き換え、`content.yaml` の `alt`(写っている内容の説明)と `caption`(場所と時間帯)を新しい写真に合わせて書き換えてから、組み立て直します。

| 写真 | 使う場所 | 書き出す幅 |
| --- | --- | --- |
| `hero-h-*` | パソコンの最初の画面 | 1280・1920・2200 |
| `hero-v-*` | スマホの最初の画面 | 640・828 |
| `present-*` | 「次の集まり」 | 800・1200・1600 |
| `work-*` | 活動「AIの勉強会」 | 800・1200・1600 |
| `town-*` | 活動「まちの課題を解く試み」 | 800・1200・1600 |
| `talk-*` | 活動「居場所づくり」 | 800・1200・1600 |
| `og.jpg` | SNS で共有したときの画像(`og:image`。`site.url` を書くと絶対 URL になる) | 1200×630。JPEG だけ |

横長の写真は 3:2 で撮ります。スマホでは左右を少し切って 4:3 で表示します。活動の最後の写真は、画面の幅が 761px 以上のとき上下を切って 21:9 で表示するので、人や机を高さの真ん中あたりに収めます。最初の画面のスマホ用は縦長(9:16 前後)で、上に照明、真ん中に人、下3分の1は床か机にします。

## 公開

静的なファイルだけなので、Netlify、Cloudflare Pages、GitHub Pages などにそのまま置けます。Ad Grants の条件として、団体が持つドメインで HTTPS で公開してください。

## 動作環境

最近の Chrome、Edge、Safari、Firefox で確かめる想定です。日本語の改行位置を整える `word-break: auto-phrase` は Chrome と Edge だけで効きます。ほかのブラウザでは、ふつうの改行で表示されます。
