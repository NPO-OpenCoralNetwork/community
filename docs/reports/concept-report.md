# オープンコミュニティ構想 整理レポート

Oct 23, 2026 · @k10

## 目的と前提

このレポートは、NPO法人 Open Coral Network が構想段階で「やろうとしていること」を、射水向け提案書から地域固有の内容を省いて整理したものです。特定の地域に依存しない形にし、Google Ad Grants を使った新しいコミュニティ募集の土台として使うことを想定しています。

- 元資料は「ミライを育てる学校」への提案書(2026年10月、本編26枚と付録20枚)です。市の数字、跡地施設の工程、地域の相談窓口、県の調査など、射水・富山に固有の記述は扱いません。
- 併せて、組織ハンドブック(open-coral-handbook)とコミュニティ案内サイト(npo-open-community)の2つのリポジトリを読みました。3つ目の community リポジトリは空でした。
- 提案書の「案」「将来構想」「確認」の札は、すべて未決のまま扱います。このレポートに書かれていることは、どれも決定事項ではありません。
- 新しい前提として、Google Ad Grants の承認を得ています。新ドメインのサイトで申請し、無料広告でコミュニティ参加者を募る方針です。

## 構想の全体像

構想の骨格は、物語で集め、サイトで迎え、場と伴走で続けてもらい、人・道具・知識・仕事を地域に残す、という一本の流れです。Google Ad Grants はこの流れの入口を広げる手段で、構想そのものは提案書とハンドブックから変わっていません。

[embedded content: 構想の全体像 · 物語・募集・入口・コミュニティ・運営基盤]

物語が広告とサイトの言葉を決め、コミュニティで生まれた参加者の物語が次の言葉に戻る循環です。運営基盤は入口とコミュニティの両方を支えます。

## コミュニティの仕組み

仕組みの考え方は「一人ひとりの努力だけに頼らず、挑戦できる環境をつくる」です。参加者の歩みを5つの段に分け、段ごとに会える場と、使える道具を用意するのが提案書の設計です。

[embedded content: 参加者の歩み · 5段 × 場・道具]

上の段は提案書の「ある人の歩み」を地域名なしに言い換えたもので、各段の場と道具はどれも一緒に決める前提です。参加の層(ビジター→メンバー→貢献メンバー→コアメンバー)は旧コミュニティ案にあり、段との対応はまだ決まっていません。貢献への報酬(フェア・バウンティ)と、決めるのは人という原則は、どの段にもかかります。

## Google Ad Grants を使った会員募集の流れ

広告は無料ですが、Ad Grants の要件はサイト側と運用側の両方にかかり、参加登録の計測が両者をつなぐ要になります。月の広告費は最大1万ドル相当です([Ad Grants 概要](https://www.google.com/intl/ja/grants/))。要件は Google の公式ポリシーから引用しました。

[embedded content: 広告から参加まで · 5段階と要件]

要件を満たせないと広告が止まるため、サイトを作る段階で計測と地域設定まで決めておく必要があります。コミュニティに入った後は広告の要件の外なので、続けてもらうのは場と伴走の仕事です。

### 要件の要点(公式ポリシーより)

| 要件 | 内容 | かかる場所 |
| --- | --- | --- |

| 新ドメインの承認 | 追加ウェブサイトドメインのリクエストフォームから申請。審査は3〜5営業日 | 申請 |
| サイトの中身 | 活動に直接関連する独自コンテンツ、ミッション・概要・連絡先、HTTPS、モバイル対応、第三者広告なし | サイト |
| キーワード | 広告とキーワードは団体の主な活動目的を反映し、プログラムやサービスとの関連が高いもの。1語のキーワード(自団体のブランド名などを除く)、一般的すぎる語、他団体名・地名だけの語は不可。品質スコアが1〜2の語は一時停止する | 運用 |
| クリック率 | 毎月5%以上(アカウント単位)。2か月連続で未達なら一時停止 | 運用 |
| コンバージョン | 1種類以上を設定し、月1件以上。会員登録やボランティア登録が例 | サイトと運用 |

## サイト・ドメイン・運営基盤

新ドメインのサイトは、Ad Grants の「団体の公式サイト」としての要件と、コミュニティの入口としての導線を一つのサイトで満たす必要があります。いまの公式ポータル(Nexloom)は vercel.app のサブドメインにあり、ポリシーの「団体が所有するドメイン」として説明しにくいため、広告のリンク先には使わず、団体名義の新ドメインを取得する前提にします。

### 新ドメインで作るサイトの構成案

| ページ | 役割 | Ad Grants 上の意味 |
| --- | --- | --- |
| ホーム | 世界観の一文と、ミッションを目立つ位置に | ミッションの明示、独自コンテンツ |
| 団体について | 法人名、所在地、法人番号、年次報告、財務情報 | 団体情報と財務情報の明示 |
| 活動・プログラム | 定例イベント、Civic AI の循環、自作の道具の紹介 | 活動に直接関連する十分な量の内容 |
| 参加する | 参加フォーム。送信完了をコンバージョンにする | コンバージョン計測(月1件以上) |
| お知らせ・イベント | 開催予定と報告。続いている証拠 | 継続的な活動の提示 |
| 寄付(任意) | 安全な寄付専用ページ | 寄付リンクの要件 |
| お問い合わせ | 連絡先 | 連絡先ページ |

技術面では、サイト全体の HTTPS 化と HTTP からの自動転送、モバイル対応、読み込み速度、リンク切れの点検が要ります。AdSense などの第三者広告や、他サイト・SNS への自動転送は置けません。

## 段階的な進め方(ロードマップ案)

進め方は5つの順番で、日付はどれも未定です。ドメインの承認が下りるまで広告は出せないため、サイトの点検表を先に通すのが順番の要になります。広告を出す前にチャットと初回の定例イベントを用意し、登録した人の行き場を作っておきます。研究倫理の審査・相談の範囲も、募集の前の「1 決める」で確かめます。

[embedded content: ロードマップ案 · 5つの順番と4つの進む条件]

提案書の「まず3か月の PoC」は、聞き取り→試作と販売→有償1件という事業化の試行の設計です。コミュニティでは、90日で続ける・変える・止めるを決める枠だけを借り、中身を当てはめるかは未決事項で決めます。CTR 5%とコンバージョン月1件は、場を始める条件ではなく、広告を続けるための毎月の条件です。

## 未決事項と検討ポイント

広告の文言とサイトの内容は対象者で決まるため、最初に決めるのは「誰を募るか」です。以下は、提案書の「一緒に決めること」と、今回の募集で新たに要る判断を合わせたものです。

- [ ] 誰を募るか。提案書は挑戦する若い世代、旧案は AI とプログラミングの個人開発者、ハンドブックは6つのロールを想定しており、対象が揃っていない
- [ ] コミュニティの呼び方と、世界観の一文
- [ ] 対象者が検索する語の候補と、広告文・サイトリンク2つの下書き
- [ ] 新ドメイン名と、サイトを置くリポジトリ(community が空いている)
- [ ] ハンドブックのうち新サイトに載せる章の範囲
- [ ] コンバージョンの定義。参加フォームの送信か、チャット(Discord/Slack)への参加か、イベント申込か。チャットは Discord か Slack か
- [ ] 広告の地域設定。全国か、活動拠点の地域に絞るか
- [ ] 広告アカウントの運用担当(毎月の CTR とコンバージョンを見る人)と、サイト更新の担当
- [ ] 参加の段階と会員形態。旧案の4段階・3形態と、ハンドブックの3ステップ・6ロールをどう一本化するか
- [ ] 参加ページとチャットに掲げる行動規範。ハンドブックの4つの約束か、旧案の行動規範か、新しく書くか
- [ ] 定例イベントの頻度、テーマ、オンラインとリアルの比率、始める時期。提案書のテーマ(創業のマインド)とハンドブックの3種のどれから始めるか
- [ ] 道具のうちコミュニティで使うもの(使わない選択も含む)
- [ ] 記録と測り方、研究として公開する範囲。研究倫理の審査・相談の範囲は、募集の前に確かめる
- [ ] 参加フォームで集める項目と保存期間
- [ ] 費用と財源。90日 PoC の設計例をこのコミュニティに当てはめるか
- [ ] ハンドブックのマーケティング方針への Ad Grants の位置づけ
