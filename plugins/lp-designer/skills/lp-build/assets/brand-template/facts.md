# <団体名> の事実

ページや資料に書く事実は、この表にあるものだけを使います。表にない事実を書きたいときは、先に出典を確かめて行を足してから使います。

出典には、資料の場所(リポジトリの中のパスや URL)を書きます。人から聞いて決まったことは、「依頼(2026-10-25、運営チームから)」のように、日付とだれから聞いたかを書きます。

ページに書くけれど、まだ確かめきれていない事実は、「ページでの書き方」の欄に `**要確認**:理由` と書きます。組み立てると、公開の前に運営が確かめることとして一覧に出ます。ページに書かない事実には付けません。

## 決まっていないこと

ページでは書かないか、`[日時]` のように角括弧で示します。

- コミュニティの名前
- 次の集まりの日時、会場、参加費
- 参加登録フォームの送信先、Google 広告のタグ
- 所在地(番地まで)、代表者の役職と氏名、設立年月日
- 問い合わせ先のメールアドレス
- 申込や記録の保存期間、フォームやメールに使うサービス
- プライバシーポリシーの制定日
